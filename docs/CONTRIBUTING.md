# Contributing

All contributors and coding agents must follow the repository `AGENTS.md`.

Before implementation:
- Read the approved specification.
- Confirm the task belongs to the current roadmap stage.
- Avoid changing product scope without owner approval.
- Document architectural/security decisions in ADRs.

Changes should be small and independently verifiable. Include tests and report only checks that were actually executed.

External coding agents may help develop the repository. This does not mean the Astra product itself may use multiple AI agents at runtime.
