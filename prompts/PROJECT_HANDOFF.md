# Project Handoff

Astra Agent is an approved local-first autonomous AI agent project.

Non-negotiable product requirements:
- One runtime agent, not a multi-agent system.
- Multiple local models are allowed as interchangeable engines.
- No cloud AI APIs or third-party AI assistants in product runtime.
- Windows primary, Linux supported, Android remote client.
- LAN-only access; no public internet exposure.
- Continuous host process; load LLMs on demand.
- User approval for critical operations, production deployment, core/security policy changes.
- Memory independent from model.
- Skills may be versioned, tested, and applied automatically when safe.
- Full software development lifecycle capabilities are a product goal.
- Security and permission checks are enforced outside the LLM.

Current status:
- Stage 0 completed.
- Product specification approved on 2026-11-18.
- Implementation not started.
- Next stage: Foundation.
