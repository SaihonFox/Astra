# Documentation Maintenance Skill

- Keep README, architecture, API, security, roadmap, and project status aligned with actual code.
- Distinguish implemented, planned, experimental, and deprecated features.
- Include exact prerequisites and commands only when verified.
- Update ADRs for significant decisions.
- Never claim unsupported platform compatibility.
- Record known limitations and open risks.
- Keep the approved product specification stable; propose changes separately for owner approval.
