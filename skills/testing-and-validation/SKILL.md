# Testing and Validation Skill

1. Derive acceptance criteria from the task.
2. Test behavior, edge cases, cancellation, errors, and recovery.
3. Add unit tests for deterministic logic.
4. Add integration tests for persistence, IPC, and adapters where appropriate.
5. Add architecture tests for dependency boundaries.
6. Add security tests for permission bypass and untrusted inputs.
7. Run the relevant build and tests.
8. Record exact commands, environment, pass/fail counts, and skipped tests.
9. Never claim a test passed if it was not executed.
10. Update docs when behavior or requirements change.
