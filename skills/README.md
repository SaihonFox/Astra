# Agent Skills

Skills are task-specific working procedures for coding agents contributing to this repository. They do not represent runtime agents inside Astra.

Each skill lives in its own directory and contains `SKILL.md`. Read the relevant skill before performing that kind of work.

Available skills:
- `architecture-review`
- `dotnet-engineering`
- `security-review`
- `testing-and-validation`
- `research-and-dependencies`
- `documentation-maintenance`
